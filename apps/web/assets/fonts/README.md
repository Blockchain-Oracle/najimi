Fonts for link-preview images (`lib/og.tsx`): `next/og` needs TTF files, read from disk once.
Bricolage Grotesque and IBM Plex Sans (+ Arabic) are under the SIL Open Font License 1.1
(https://openfontlicense.org), downloaded from Google Fonts.
Funnel Display (800) and Funnel Sans (400, 600), the app's own faces since S01, are WOFF files from
Google Fonts under the same licence (next/og reads WOFF as well as TTF).
